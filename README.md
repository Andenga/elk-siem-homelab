Temperature Conversion Program (JavaScript)

🌡️ Description:
This GitHub repository hosts a simple yet powerful temperature conversion program built using JavaScript. It enables users to effortlessly convert temperatures between Celsius, Fahrenheit, and Kelvin scales, making it a valuable tool for diverse industries and applications.

🚀 Features:
- Convert temperatures between Celsius, Fahrenheit, and Kelvin.
- User-friendly and intuitive interface for easy interaction.
- Robust and accurate conversions for reliable results.
- Seamless integration with HTML and CSS for a visually appealing experience.
- Lightweight and efficient implementation for optimal performance.

🔧 Usage:
1. Enter the temperature value in the input field.
2. Select the current scale (Celsius, Fahrenheit, or Kelvin) from the dropdown.
3. Choose the desired scale for conversion from the other dropdown.
4. Instantly view the converted temperature with precision.
